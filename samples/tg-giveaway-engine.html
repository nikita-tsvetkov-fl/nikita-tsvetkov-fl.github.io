Движок розыгрыша Telegram: звёзды / NFT / подарки рабочий образец

Ядро mini-app розыгрыша под ТЗ: админ задаёт банк звёзд и число мест, звёзды делятся между победителями поровну, шанс выигрыша взвешен по билетам, подарки раздаются по рангу, NFT всегда достаётся игроку №1. Ниже — реальный прогон движка на тестовом раунде из 83 участников. Чистый Python, без зависимостей; в проект встраивается за бэкендом mini-app, выдачу звёзд/подарков исполняет Bot API бота заказчика.

3. Честность раунда (provably-fair)

Главная боль таких розыгрышей — споры «результат подкручен». Здесь это закрыто математикой, а не словами:

  • Взвешенная жеребьёвка по билетам без повторов — метод Efraimidis–Spirakis (A-Res), корректный сразу для нескольких мест: чем больше билетов, тем выше шанс, но исход не предопределён.
  • Детерминированный seed раунда. Результат полностью воспроизводится из seed; reveal_salt публикуется ПОСЛЕ розыгрыша, и любой участник может пересчитать и убедиться, что итог не меняли.
  • Гарантии ТЗ соблюдены проверяемо: звёзды поделены поровну, NFT — игроку №1, подарки по рангу билетов среди победителей.

4. Как встраивается в проект

  • participants/tickets приходят из БД mini-app (фронт mini-app + бэкенд + админка — часть полного проекта).
  • Доставка звёзд и подарков — через Bot API бота заказчика (Stars через инвойсы, NFT/подарки через методы gifts).
  • Движок отдаёт готовый план «кому сколько звёзд и какие подарки» + provably-fair лог — бэкенд просто исполняет выдачу.
