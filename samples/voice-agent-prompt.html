Голосовой ИИ-агент для клиники — промт под ключ (без кода)

Демонстрация того, как я собираю промт для голосового агента на готовом сервисе (Vapi / ElevenLabs / LP Tracker и т.п.) — на стороне личного кабинета, со связкой в CRM клиента. Кейс-образец: медицинская клиника (учебный, не реальный заказчик).

Методология. Не «простыня инструкций», а инженерная конструкция: состояния диалога → правила перехода → тон → выгрузка в CRM, плюс RAG-база, чтобы агент отвечал строго по материалам клиента, а не выдумывал. Это даёт предсказуемый диалог без срывов и юридически безопасную работу в чувствительной нише (медицина).

Почему так работает

Состояния, а не «простыня»

Агент всегда знает, на каком шаге он находится и куда переходить — меньше срывов и зацикливаний диалога.

Жёсткие стоп-правила

Для медицины: никаких диагнозов и дозировок. Юридически и репутационно безопасно по умолчанию.

Ответы только из RAG

Нет данных в базе → «уточню и перезвоню» + фиксация заявки, а не выдумка факта.

Готовая выгрузка в CRM

Каждое поле карточки определено заранее — заявка не теряется и попадает менеджеру тёплой.

1. Сценарий ВХОДЯЩИХ (реактивный)

Приём входящего звонка: выявить запрос, ответить по базе, записать на приём.

Приветствие→ Выявление потребности→ Ответ по базе (RAG)→ Запись на приём→ Закрытие → CRM

Из любого состояния вызывается Отработка возражений («дорого» / «подумаю» / «далеко»).

Жёсткие правила (фрагмент SYSTEM-промта)

Никаких диагнозов, дозировок, прогнозов лечения.
На медицинские вопросы: «Это уточнит врач на приёме, давайте я вас запишу».
Цены, услуги, адрес, график — ТОЛЬКО из базы знаний (RAG).
Нет данных → «Уточню и перезвоню», фиксируешь вопрос в заявку.
Персональные данные подтверждаешь по буквам/цифрам (имя, телефон).
Один шаг за раз: не вываливаешь весь список услуг сразу.

2. Сценарий ОБЗВОНА базы (проактивный)

Агент сам звонит по базе: реактивация, напоминание о недозаписи, акция, возврат «спящих» пациентов — с уважением к «нет».

Открытие (≤2 фразы)→ Проверка удобства→ Оффер→ Работа с реакцией→ Запись→ Закрытие → CRM

Ключевые переходы (комплаенс обзвона)

  • «Кто это? / Откуда номер?» → клиника + причина + «ваш контакт у нас в базе как пациента». Не успокоился → извиниться, завершить, пометить.
  • Явный отказ / «удалите из базы» → подтвердить, статус стоп-лист, конец. Согласие на обзвон уважается всегда.
  • Автоответчик → короткое сообщение из шаблона, статус «ВМ».

3. База знаний → RAG-чанки

Исходники клиента (прайс, расписание, скрипты продаж, транскрибации звонков) раскладываются в самодостаточные чанки под векторный поиск. Агент отвечает строго по ним.
