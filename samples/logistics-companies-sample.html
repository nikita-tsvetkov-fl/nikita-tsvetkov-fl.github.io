Сбор и систематизация: логистические компании для e-commerce

Демо-сэмпл методики (9 записей). Полный сбор — по согласованному ТЗ. Формат единый, без дублей, с проверкой актуальности.

Методика:
  1. Источники: офиц. сайты, бизнес-каталоги, публичные справочники.
  2. Поля по каждой компании: название, страна, города, услуги, контакты, ссылка.
  3. Унификация услуг к единому словарю (courier / pvz / warehouse / fulfillment / cargo / intl) — формулировки приведены к одному виду для анализа.
  4. Дедуп по нормализованному названию: дублей в выборке — 0.
  5. Проверка актуальности: пинг офиц. домена; устаревшие/слитые бренды помечаются. Пример — Boxberry теперь под Яндекс.Доставкой (boxberry.ru → редирект).
