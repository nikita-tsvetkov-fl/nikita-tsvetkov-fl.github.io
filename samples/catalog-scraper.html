Каталог-скрапер: товарные страницы → структурированный CSV

Сбор данных товаров (e-commerce) в чистую таблицу. Устойчив к анти-боту и к смене вёрстки.

Как устроено — два слоя

листинг категории→ ссылки на товары→ FETCH-слой→ PARSE-каскад→ CSV / Excel / JSON
FETCH-слой (откуда берём HTML) — подключаемый:
  • http — обычный запрос для открытых сайтов;
  • residential — рендер через реальное устройство / резидентный канал для сайтов за Akamai / Cloudflare. Пример: hm.com отдаёт датацентр-IP 403 Access Denied — наивный парсер тут падает, residential-канал проходит. Парсер при этом тот же.
PARSE-каскад (как достаём поля) — по убыванию надёжности:
  • 1 JSON-LD schema.org/Product
  • 2 микроразметка itemprop + таблица атрибутов
  • 3 OpenGraph / мета-теги

Не завязан на один хрупкий CSS-селектор — если сайт меняет вёрстку, сбор не ломается.

Живой прогон воспроизводимо

Реальный сбор каталога (категория «Mystery») в один проход. Поля: название, артикул, цена, валюта, наличие, категория, ссылка. Ниже — фактический результат, полный файл: catalog-scraper-sample.csv.

Что получает заказчик

  • выгрузка в CSV / Excel / JSON по согласованному набору полей;
  • дедупликация и лог ошибок (битые карточки не роняют прогон);
  • разовый сбор или регулярное обновление по расписанию;
  • для защищённых сайтов — сбор через residential-канал без банов и капч.
