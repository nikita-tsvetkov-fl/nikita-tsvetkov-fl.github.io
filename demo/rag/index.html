Как это работает

  1. Ingest — читает .txt / .md / .pdf (PDF через pdfplumber, сканы — с OCR).
  2. Chunk — режет по границам предложений с перекрытием, контекст не рвётся.
  3. Index — TF-IDF + лёгкий RU/EN стеммер, косинусная близость (офлайн, без ключей).
  4. Retrieve — top-k фрагментов с оценкой и ссылкой на файл-источник.
  5. Answer — ответ из найденного + цитаты. Нет в базе → честно «не нашлось».

Это retrieval-слой (лексический, офлайн). В боевом проекте эмбеддинги меняются на семантические (Anthropic / OpenAI), а ответ — на вызов LLM с найденным контекстом и инструкцией «отвечай только по источникам». Архитектура та же; векторное хранилище масштабируется на FAISS / pgvector / Qdrant.
